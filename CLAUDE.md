## Current Baseline

- The Streamlit application entry point is `category_tracking_web.py`.
- `category_tracking.py` is the supported legacy Tkinter and tuple-compatibility adapter.
- `engine/` is the single source of truth for biological definitions, exact and sampled simulation, analysis, and scientific summaries.
- Phase 1 is implemented according to `../plans/phase-1-extract-ui-independent-engine.md`; its evidence is in `../plans/phase-1-execution-log.md`.
- Phase 2 is implemented according to `../plans/phase-2-strengthen-computation.md`; its evidence is in `../plans/phase-2-execution-log.md`.
- Phase 2 exact analysis is the authoritative deterministic scientific API for new callers.
- Phase 2 aggregated sampled mode is an explicit engine-only experimental API. Do not expose it in Streamlit without a new approved Blueprint mutation.
- `diagnose_category_tracking_web.py` and `tests/compat/diagnose_category_tracking_web_phase1_baseline.py` are frozen compatibility oracles.
- `tests/fixtures/phase1_scientific_baseline.json` and `tests/fixtures/phase1_streamlit_surface.json` are immutable reviewed baselines and must never be regenerated by tests.
- `tests/fixtures/phase2_scientific_contract.json` is the reviewed Phase 2 contract fixture and must never be regenerated by tests.
- Use standard-library `unittest`; run `python -m unittest discover -s tests -p "test_*.py"` from this directory.

## Implemented Architecture

- `engine/genetic_code.py` owns codons, amino-acid properties, category labels, and grouping helpers.
- `engine/mutation_matrix.py` owns probability presets and substitution-matrix construction.
- `engine/exact_tracking.py` and `engine/sampled_tracking.py` own the two simulation algorithms.
- `engine/category_analysis.py` and `engine/summaries.py` own scientific DataFrame transformations, denominators, convergence, and outcome tables.
- `engine/models.py` defines `ExactSimulationResult` and `SampledSimulationResult` plus explicit legacy tuple conversions.
- `category_tracking_web.py` owns Streamlit validation, caching compatibility, Plotly charts, accessibility, and presentation.
- `category_tracking.py` owns Tkinter presentation and compatibility wrappers only.

## Preservation Rules

- Exact same-process results must match in container type/order and `float.hex()` values.
- Sampled results must preserve module-level `random`, mutation draw order, paths, early stops, copy numbering, and final RNG state.
- Preserve the denominator and zero behavior documented in `engine/README.md`.
- New code consumes named result fields. Tuple conversion is allowed only in explicit compatibility boundaries.
- Do not import UI frameworks, presentation colors, HTML, or CSS into `engine/`.
- Do not add scientific arithmetic to Streamlit render functions or duplicate biological tables/simulation loops.
